# Use Cases — portunix-agent

## Overview

Use cases are tracked as Markdown files in this directory. Each UC describes a specific interaction between an actor and the system including preconditions, main flow, alternative flows, postconditions, and acceptance criteria.

### Naming Convention

- File format: `UC-{NNN}-{slug}.md` (e.g., `UC-001-remote-keyboard-control.md`)
- Sequential numbering starting from 001

### Relationship to Issues

Each use case may have one or more related issues in `docs/issues/` that track its implementation. The UC file references related issues and vice versa.
